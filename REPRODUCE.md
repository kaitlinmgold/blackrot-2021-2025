# Reproducing the analysis

Run from the repository root. `results/` holds recorded numerical results; commands below write new model results to `rerun/`. Figures write beside their source scripts, so use a working copy for figure exports. RDS model objects are generated by the fitting commands rather than distributed.

## Software

The recorded analysis used R 4.5.3, glmmTMB 1.1.14, emmeans 2.0.4, jsonlite 2.0.0, and sandwich 3.1-2. See `results/primary/R_session_info.txt` for the full environment. Install these packages in R (matching recorded versions for closest numerical reproduction):

```r
install.packages(c("glmmTMB", "emmeans", "jsonlite", "sandwich"))
```

Figure code requires Python 3 with NumPy, pandas, and Matplotlib (`python3 -m pip install -r requirements.txt`). Raster export additionally needs Node.js and Sharp (`npm install`). Figures 2, 3, and S1 can be regenerated as SVG with Python's standard library alone. Figure 1 is supplied as a native SVG. Matplotlib 3.11.2 and Sharp 0.35.4 were used for the supplied artwork; font/library changes may affect appearance.

## Check the data

```sh
python3 scripts/check_data.py
```

This checks file hashes, program/plot joins, reconstruction of cluster endpoints, and recorded trial-window totals. It does not fit models.

## Primary and secondary models

```sh
Rscript scripts/blackrot_v4_reanalysis.R data rerun/primary
Rscript scripts/refit_bootstrap_primary_tests.R data rerun/primary/primary_models.rds rerun/primary_bootstrap 9999 4 20260831
Rscript scripts/blackrot_v4_secondary_reanalysis.R data rerun/secondary
Rscript scripts/bootstrap_incidence_interaction_refit_score.R rerun/secondary/metal_any_models.rds rerun/secondary metal_any_incidence 1999 4 20260832
Rscript scripts/bootstrap_incidence_interaction_refit_score.R rerun/secondary/metal_strict_models.rds rerun/secondary metal_strict_incidence 1999 4 20260833
Rscript scripts/refit_bootstrap_secondary_severity.R rerun/secondary/metal_any_models.rds rerun/secondary metal_any 1999 4 20260841
Rscript scripts/refit_bootstrap_secondary_severity.R rerun/secondary/metal_strict_models.rds rerun/secondary metal_strict 1999 4 20260851
Rscript scripts/blackrot_v4_descriptive_outputs.R data rerun/descriptive
```

Bootstrap runs are computationally intensive. Seeds, simulation counts, and four-core execution match the recorded specifications. Severity bootstrap scripts add test-specific offsets: primary +1/+2; secondary +1/+2. Numerical results and failed-refit counts can vary with software and optimizer behavior. The primary bootstrap script also writes approximate pooled summaries; manuscript primary pooled summaries come from the additive fits in `results/primary/`.

## Assignment sensitivity and program diagnostics

Run the primary model command above first to generate its model objects, then:

```sh
Rscript analyses/sensitivity_2022/run_additive_sensitivity.R data rerun/primary rerun/sensitivity/additive
Rscript analyses/sensitivity_2022/prepare_interaction_models.R rerun/sensitivity/additive/sensitivity_primary_additive_models.rds rerun/sensitivity/interaction_inputs
Rscript analyses/sensitivity_2022/run_incidence_interaction_bootstrap.R rerun/sensitivity/interaction_inputs rerun/sensitivity/interaction_inputs/interaction_models.rds rerun/sensitivity/incidence 1999 8 20260911
Rscript analyses/sensitivity_2022/run_severity_interaction_bootstrap.R rerun/sensitivity/interaction_inputs rerun/sensitivity/interaction_inputs/interaction_models.rds rerun/sensitivity/severity 9999 8 20260911
Rscript analyses/secondary_diagnostics/run_secondary_diagnostics.R . rerun/secondary_diagnostics
```

The sensitivity severity seed is the supplied seed +2. To recreate the two sensitivity summary tables from the recorded numerical results without fitting models:

```sh
python3 analyses/sensitivity_2022/summarize_public_sensitivity.py analyses/sensitivity_2022
```

## Figures

```sh
python3 scripts/blackrot_publication_figures.py results figures
node scripts/render_publication_figures.mjs figures
python3 figures/program_control_v5.0/prepare_control_tables.py
python3 figures/program_control_v5.0/make_double_panel_figures.py
python3 descriptive_newa_timeline/make_timeline.py
```

The first two commands regenerate Figures 2, 3, and S1 from recorded model summaries and export Figures 1–3/S1 at 600 dpi. The next two derive program control from plot observations and render Figures 4–5. The final command rebuilds the NEWA timeline (Figure 6) from the archived weather tables. These figure commands do not fit statistical models. Dataset hashes apply to the distributed files before local reruns.
